Goal：识别图像中每个目标的类别并对它进行定位（位置+尺寸）

通过两个框内像素集合的IoU来定义两个框的重合度：$$\texttt{IoU}(\mathcal{A},\mathcal{}B)=\frac{\mathcal{A} \cap \mathcal{B}}{\mathcal{A} \cup \mathcal{B}}$$
# R-CNN

不遍历所有位置所有尺寸的窗口，只需要找到可能存在目标的候选窗口，然后再用卷积神经网络对这些候选窗口做分类

---
**Selective Search**
基于图像分割的层次合并算法

1. 初始过分割
   把图像切分成大量小的初始像素区域
2. 对任意两个相邻区域，计算相似度（颜色、纹理、尺寸等）
3. 贪心合并
   把相似度最大的两个区域进行合并
---
1. 对原图进行 Selective Search，生成候选窗口
2. 对每一个候选框做裁剪 + Warp 缩放
3. 进行 CNN，提取每个框的特征向量
4. SVM 分类器做类别判断
5. Bounding‑Box 回归
	对每一个类别，单独训练一个线性回归模型
	- 输入：原始候选框
	- 输出：修正的位移
6. 非极大值抑制 NMS
   对每一个类别，取出分数最高框，把其余和它 IoU 大于阈值的框全部删除
# Fast R-CNN

R-CNN 的缺陷：
- 对每个候选区域都需要使用 CNN 主干网络计算一次特征，计算效率低
- SVM 分类和坐标回归的结果无法反馈给前端的 CNN 主干网络用以更新网络参数

1. Selective Search，生成候选窗口
2. 整张原图送入骨干 CNN，得到共享 feature map
3. 通过数学变换，把原图的框坐标映射到卷积后的 feature map 上，得到多个 ROI 区域
4. 将 ROI 区域池化成固定大小
5. continue as R-CNN
