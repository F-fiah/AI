# Vim

`esc` + `:wq` 保存并退出
`esc` + `:q`   直接退出
# 基本指令
## 目录文件

- `pwd` 显示当前目录路径
- `ls` 显示文件
	`-a` 表示同时显示隐藏文件
	`-lh`
- `cd` 
- `mkdir` 
	默认只创建一级文件
	若创建多级，则使用 `mkdir -p` 
- `rmdir`
	默认删除空目录
	若删除非空目录，使用 `rm -rf` 
- `touch` 创建空文件
- `cp` 对文件进行拷贝
	若拷贝文件夹，则 `cp -r` 
- `rm` 
	删除文件或目录
	`rm -r` 递归删除整个文件夹
- `mv` 一定文件/目录或重命名
- `cat` 查看文件内容
	`-n` 显示行号
- `>` 重定向，将输出内容覆盖写入指定地方
- `>>` 追加，将输出内容追加写入指定地方
- `ln` 软链接，相当于快捷方式
	`ln -s [原文件/目录][软链接名称]`
- `history` 查看历史指令
## 查找类

- `find` 从指定目录向下递归遍历各个子目录，将满足条件的文件/目录显示在终端
	- `-name` 
	- `-user` 
	- `-size`（+n 大于；-n 小于；n 等于）
- `locate` 定位文件的位置
  使用之前要先执行 `updatedb` 指令创建 locate 数据库
- `which` 查找某个指令的位置
- `grep` 过滤查找
	常与管道符 `|` 一起使用
	`grep 查找内容 源文件`
	`-n` 显示行号
	`-i` 忽略字母大小写
## 压缩与解压类

- `gzip` 压缩文件
- `gunzip` 解压缩
- `zip` 压缩文件/文件夹
	默认压缩文件，若要压缩文件夹，使用 `-r`
- `unzip` 
- `tar` (.tar.gz 文件)
	`tar [选项] xxx.tar.gz 打包的内容(多个文件用空格隔开)`
	- `-c` 产生 .tar 打包文件
	- `-v` 显示详细信息
	- `-f` 指定压缩后的文件名
	- `-z` 打包同时压缩
	- `-x` 解包 .tar 文件
	通常使用 `zcvf` `zxvf`
# 权限
## 所有者 所有组

文件的所有者默认为其创建者，所有组默认为创建者所在的组

`chown 用户名 文件名` 修改文件的所有者
`chgrp 组名 用户名` 修改文件的所在组

`useradd -m 用户名` 创建用户，默认创建一个和用户名同名的主组
`groupadd 组名` 创建组

`usermod -g 新组名 用户名` 改变用户所在组
## 文件及目录权限

`-rwxrw-r--`
- 第0位：文件类型
- 1~3位：文件所有者对该文件的权限
- 4~6位：同组的用户对文件的权限
- 7~9位：其它用户对文件的权限

- `r` 可读
- `w` 可写
- `x` 可执行
## 修改权限

- `u` 所有者
- `q` 所有组
- `o` 其他人
- `a` 所有人

```
chmod u=rwx,g=rx,o=x 文件/目录名
chmod o+w 文件/目录名
chmod a-x 文件/目录名
```

# 进程

- `ps` 查看设备当前正在进行的进程
	- `-a` 显示所有进程信息
	- `-u` 以用户形式显示进程信息
	- `-x` 显示后台进程运行的参数
- `kill 进程号` 终止进程
