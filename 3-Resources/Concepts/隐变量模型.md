# AE

- 编码器：将数据压缩为低维空间的抽象表示、
- 解码器：解压缩编码信息并重建数据

GOAL：最小化原始图像和重建图像之间的差异（即图像之间的像素级平均绝对误差）

缺陷：
- 编码过程中可能会丢失信息，导致重建结果的准确性降低
- 难以生成高质量图像（大量数据和算力）
- 无法生成训练集中未见过的新图像
# VAE

参考：[[Generative Model#Variational Autoencoders]]

**AE 不擅长差值：无法在两个输入数据点之间生成处于中间状态的表示**

VAE 与 AE 的区别：
- AE 将每个输入编码成潜空间的一个特定点
- VAE 将其编码成潜空间的概率分布（常为正态分布）

训练指标：
- 重建损失
- KL 散度：衡量一种概率分布与另一种预期概率分布发散程度的指标
  利用 KL 散度，可以实现对学习到的分布与先验分布（标准正态分布）之间的偏差进行惩罚，从而促使编码器学习有意义且可泛化的潜在表达（捕捉数据的底层分布，从而使空间具有连续性和可解释性）

**Core : explicitly model image features using latent variables z**

隐变量通常是对于生成图像较为重要的因素
隐变量是一个向量，其维度是人为选取的超参数

If z choosen properly, $p(x|z)$ would be much simpler than $p(x)$  
$$p(x) = \int p(x|z)\,p(z)\,\mathrm{d}z$$
通常我们假设 $p(x|z)$ 和 $p(z)$ 都具有较为简单的形式 
1. $z \sim \mathcal{N}(0, I)$ 
2. $p(x|z) = \mathcal{N}\big(\mu_\theta(z), \Sigma_\theta(z)\big)$ 
   where $\mu_\theta, \Sigma_\theta$ are neural networks

即从一个简单的分布中采样隐变量 z，然后通过一个复杂的非线性函数（由神经网络参数化）将 z 映射为 x

**如何得到隐变量：Encoder**

向编码器输入一张真实图片，编码器通过卷积计算，回归得到均值向量 μ 和一个方差向量 σ，即对后验分布 $p(z∣x)$ 进行建模
$$p(z|x) = \frac{p(x|z)\,p(z)}{p(x)} = \frac{p(x|z)\,p(z)}{ \int p(x|z)\,p(z)\,\mathrm{d}z}$$
- Problem：z 的维度通常很大，计算积分 $\int p(x|z)\,p(z)\,\mathrm{d}z$ 需要对所有可能的 z 值进行无穷无尽的累加，在数学上不可解
- Solution：使用高斯分布 $q(z|x)$ 替代 $p(z|x)$ 

数学推导可得：
$$\ln p(x) \ge \int q_\phi(z|x)\log p_\theta(x|z)\mathrm{d}z -\int q_\phi(z|x)\log\frac{q_\phi(z|x)}{p(z)}\mathrm{d}z$$
完成对 $p(z∣x)$ 的建模后，即可训练解码器：
1. 对于训练集里的每一张图片 x，从完美的 $p(z∣x)$ 中采样出一个对应的 z
2. 把这个配对样本扔给解码器 $p(x∣z)$，用梯度下降调整解码器参数 θ
3. 训练好解码器后，从 z 的分布中随机选取一个隐变量，通过解码器生成图像
# Diffusion

参考：[[Generative Model#Indirect (Diffusion Model)]]

核心：通过前向扩散过程迭代地破坏数据中的结构，但后学习反向扩散过程来恢复数据中的结构
## 前向扩散

不断往图像中加入高斯噪声，$x_t = \sqrt{1-\beta_t}\cdot x_{t-1} + \sqrt{\beta_t}\cdot \epsilon$
经过数学推导可得：$$ x_t = \sqrt{\bar{\alpha}_t}\cdot x_0 + \sqrt{1-\bar{\alpha}_t}\cdot \epsilon $$ 其中 $\alpha_t = 1-\beta_t,\quad \bar{\alpha}_t = \prod_{s=1}^{t}\alpha_s, \quad \epsilon \sim \mathcal{N}(0, I)$
## 反向扩散

构建神经网络 $p_\theta(x_{t-1}|x_t)$，让神经网络去预测前向过程中被添加进去的噪声 $\epsilon_t$

经过数学推导可得：
$$ x_{t-1} = \frac{1}{\sqrt{\alpha_t}} \left( x_t - \frac{1-\alpha_t}{\sqrt{1-\bar{\alpha}_t}} \cdot \epsilon_\theta(x_t,t) \right) + \sqrt{\frac{1-\bar{\alpha}_{t-1}}{1-\bar{\alpha}_t}} \cdot \beta_t \cdot z $$
其中 $z \sim \mathcal{N}(0, I)$ 
## Diffusion + CNN

- 输入：带噪声的图像和时间步
- 输出：预测的噪声
