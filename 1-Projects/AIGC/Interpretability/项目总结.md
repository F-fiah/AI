# 阶段性总结

总结周报：[[Begin]]

**该阶段的主要工作为复现的方法，并基于这些方法，做分层实验探索**
## MLLM

对应的实验数据：[[1-Projects/AIGC/Interpretability/MLLM/Summary|Summary]]
### 关键结论

1. ViT 层有效提取出了鉴伪信息
    在不经过任何特征压缩前，ViT 能够近乎完美地捕捉到生成图像的微观伪影，这说明基础视觉编码器保留了极其丰富的高频和低频鉴伪特征
    Qwen3-VL-8B 的 SigLIP-2 展现出了惊人的泛化力，说明更先进的对比学习图文预训练（如 SigLIP）能更鲁棒地捕捉到底层伪影特征
2. 在绝大多数扩散模型测试集上，经过 Adapter 后，AUC 普遍出现了轻微到显著的下降。但在 BigGAN 的测试中，Qwen2.5-VL-3B（降维到 2048）比 7B（降维到 3584）在 BigGAN 上反而有更高的 AUC；InternVL 加上 Adapter 后在 BigGAN 上的 AUC 也逆势上升（0.7891 -> 0.8188）
3. Qwen3-VL 的架构优势：多层级特征提取极大地缓解了 Adapter 的信息丢失
    Qwen3-VL-8B 的 ViT 与 ViT+Adapter 的 AUC 数据几乎完全咬合，这说明不单纯依赖 ViT 最后一层，而是从多层级提取特征，能有效避免底层鉴伪特征在网络深层的“语义化”过程中被抹除
4. LLM 端存在严重的“鉴伪能力对齐坍塌”
5. ACC 与 AUC 的趋势背离问题
    多组数据中，AUC 下降，但 ACC 却上升，这说明 Adapter 的特征重构改变了特征空间的密度分布，导致线性探针的默认决策阈值（Threshold）发生了偏移
    说明仅用线性探针的 ACC 评估特征质量并不可靠
### 卡点

1. 黑盒化
    缺乏对特征空间分布的直观认知
	Adapter 抹除的是频域的哪一部分？是局部纹理还是全局光影一致性？
2. LLM 无法被有效“唤醒”
### 后续研究方向

#### 可解释性与特征可视化分析

- **频域分析（Fourier Analysis）**：提取真实图像与深伪图像的 ViT Token、Merge Token 和 Adapter Token，进行傅里叶变换，观察高频部分的能量谱。验证 Adapter 是否真的像我们推测的那样充当了“低通滤波器”。
    
- **空间注意力热力图（Attention Map）**：在 LLM 侧，当你向模型询问“这图是 AI 生成的吗”时，提取 LLM 交叉注意力（Cross-attention）层中对视觉 Token 的注意力权重，反投射回原图。看看 LLM 是在看“人脸边缘/背景”等容易出伪影的区域，还是仅仅在关注“语义主体”？
    
- **t-SNE 特征降维可视化**：对比不同生成器（SD vs GAN）在 ViT 层和 Adapter 层的特征聚类情况，直观证明过拟合现象以及特征映射后的分布变化。
#### 针对 LLM “语义坍塌”的旁路与提示词工程

为了解决 LLM 无法输出判断的问题：

- **Forensic Chain-of-Thought (鉴伪思维链)**：不要直接问模型“这是不是伪造的”，而是引导它先分析局部：“请检查图像中人物的手指结构是否符合解剖学？”、“请分析背景中的光影与主体是否一致，是否存在不自然的边缘融合？”，迫使 LLM 关注在 Adapter 中残留的鉴伪特征。
    
- **引入多模态线性探针引导**：既然 Adapter 输出的特征鉴伪效果很好，能否将线性探针的输出 logits 作为一个额外的“特殊文本 Token”（比如 `[Deepfake_Prob: 0.98]`）硬注入到 LLM 的 prompt 中，引导 LLM 进行最终的综合判断？
#### 深挖 Qwen3-VL 的多层级特征优势

- **层级剥离实验**：Qwen3-VL 是从多个中间层抽取特征的。可以设计探针，分别接在 Qwen3 的浅层、中层、深层的输出上，观察到底是哪一层的特征对鉴伪贡献最大。假设成立的话，浅层特征可能包含最多的高频伪影，中深层可能包含语义不一致性。这将为未来设计专门针对 deepfake-detection 的 MLLM 架构（比如专门为鉴伪设计一条跳跃连接 bypassing Adapter）提供直接的理论支撑。
## CLIP

对应的实验数据：[[1-Projects/AIGC/Interpretability/CLIP/Summary|Summary]]

![[Code_Generated_Image.png]]
### 关键结论

1. 最佳单头在跨域数据集上的 AUC 表现超越了未经消融的完整模型基线
    当使用全特征在 SDV4 上训练时，分类器过度依赖了 SDV4 特有的内容语义分布，导致在面对不同架构时泛化崩溃
	而特定的中层单头剥离了高级语义噪音，保留了极其纯粹的、跨架构通用的 AIGC 底层伪影规律
2. 模型内部特征具备极高的冗余度，“伪影鉴别”非单点单线分布
    任意单头的消融都没有造成模型鉴伪能力的大幅下降，依靠单一组件无法轻易瘫痪模型的检测能力
3. “注意力机制”是真伪辨别的核心引擎，MLP 层仅做边缘辅助
    逐层累积消融实验中，Attention 层的累积消融会导致 AUC 发生下降的程度远大于 MLP 层
### 卡点

1. 实验结果矛盾
    单头线性可分证明了中层（L8/L13）提取的独立特征判别力最强；但单头消融实验却指出，消融深层（L23_H13）对基线的破坏力最大
    可能原因：中层负责真正提取底层伪影特征，而深层 L23_H13 并不提取伪影，它负责将整个模型特征提取成 CLS Token
### 后续研究方向

1. 构建优选多头探针
    单头具有惊人的泛化能力，而 CLS Token 包含大量“语义噪音”，所以可以尝试只提取特定 head 的特征，在这个超低维度的纯净特征组合上训练分类器
2. 可解释性剖析

## Full Probe on Single Head

测量单个头的输出在完整ViT训练出的linear probe上的结果
因为最终需要对整个 ViT 进行分析，之前的[[1-Projects/AIGC/Interpretability/CLIP/Summary#线性可分]]实验更适用于仅对单个头进行分析
### 核心发现

1. L23H13 在所有数据集上都是第一，且领先幅度巨大。说明完整探针学到的决策方向 `w` 和 L23H13 的输出方向很接近
2. 绝大多数 head 的 AUC ≈ 0.5，说明它们虽然包含信息（之前的单头线性可分性实验证明了很多头 AUC 很高），但它们的信息方向与最终决策方向不一致
3. 深层头（除 L23H13）几乎不携带"决策对齐"信息
4. CLIP 在中层就形成了"真假判别方向"的雏形，这个方向在后续层中被 L23H13 进一步"锐化"和"整合"
## 特征重构

原理见：[[1-Projects/AIGC/Interpretability/CLIP/Summary#特征重构]]

将每一张图片在那个head上重构特征，用该特征在 ViT 训练出来的 linear probe 上重测 auc，如果重构前后的AUC差距较小则可以说明linear probe依据这些释义进行鉴伪

分别设置 --texts_per_head 参数为20、40、60，进行实验
### 核心发现

1. 在[[#Full Probe on Single Head]]实验中 heads 的鉴伪能力的分布和该实验的基本一致，在[[#Full Probe on Single Head]]实验中分类精度较高的 head 在该实验也具有很好的分类结果
   这说明这些 head 的判别机制**本质上是语义的**，文本方向足以表达其判别信息，这与 CLIP 模型的功能相符合
2. 增加 texts_per_head 没有显著改变 head 的 AUC，说明瓶颈是文本池的语义覆盖，而不是文本数量
3. TextSPAN 重构后，绝大部分单头判别信息丢失，只有少数中层头在重构后保留了较多信息，且跨域仍有一定泛化能力
4. 深层头（L20-L23）的判别信号难以用现有文本池表达，重构后严重退化
### 后续研究方向

1. 用 `single_head_linear_probe` 中每个头独立训练的探针，测试重构单头特征
2. **聚焦中层头构建轻量适配器**
   L5-L8 在重构后仍保留信息，所以可以直接提取这些头的原始特征，训练一个轻量适配器
## Linear Probe on LLM Token

对应[[1-Projects/AIGC/Interpretability/MLLM/Summary#LLM_2]]
直接提取 LLM 中每一层的 image token，训练 linear probe，跨数据集进行测试
### 核心发现

1. LLM 并非一定促进模型的鉴伪能力，Qwen3-VL-8B 在 Layer 1 呈现极强的分类能力
2. Diffusion 伪影呈现“浅层极强，深层严重滑坡”的趋势；GAN 结构伪影呈现“浅层弱，深层增强”的逆向趋势
   可能原因：BigGAN 伪影更多分布在全局结构不合理，需要 LLM 中深层提取结构语义关系；Diffusion 伪影主要分布在像素级高频噪声、扩散步残余纹理，Transformer 在抽象化过程中将这些信息平滑掉了
3. Qwen 模型的 acc 持续下降，InternVL 的 acc 则明显上升
### 后续研究方向

1. 跨层特征拼接
   拼接“浅层 + 中深层” 的 Image Token 特征训练线性探针，理论上可以用极低参数量在所有模型上同时打破 BigGAN 和 Midjourney 的博弈困局
2. 剖析 Qwen3-VL-8B Layer 1 的关键机制
   Gemini：“预训练极其强大的 ViT Backbone (占 95%+)” + “无损 Adapter 映射” + “第 1 层自注意力对微观/宏观空间的初级关联” 共同作用的结果
3. 从全局池化转向局部聚焦
   可参考[[What Do Visual Tokens Really Encode - Uncovering Sparsity and Redundancy in Multimodal Large Language Models]]
## AUC for Single Definition

对于每个 head（也可以只分析表现好的），计算其每个释义的  AUC 和累计的 AUC，从而量化各个释义对表征的贡献

记某个 head 的原始 image embedding 为 $c ∈ R^{N×768}$（N 张图片），用 TextSPAN 算法找到的 20 个文本方向为 $R_1, R_2, ..., R_{20} ∈ R^{768}$

**单个释义的重构：**
$$
\hat{c}_i = \frac{\langle c, R_i \rangle}{\|R_i\|^2} \cdot R_i,\quad R_i \in \mathbb{R}^{N\times 768}
$$
相当于把头输出 $c$ 投影到 $R_i$ 这一维子空间上

**累计 k 个释义的重构：**
$$
\hat{c}_{1...k} = \sum_{i=1}^{k} \frac{\langle c, R_i \rangle}{\|R_i\|^2} \cdot R_i
$$
即把头输出 $c$ 投影到 $R_1, ..., R_k$ 张成的 $k$ 
### 核心发现

*L5H2、L8H6、L8H11 是最稳定、最值得深入分析的 head*

- 鉴伪能力并不是均匀分布在所有 text 上，而是集中在少数 head-text 组合中
    Like L5H2：
	- 第一个 text 的 single AUC 只有 0.0837；
	- 加入第二个 text 后累计 AUC 直接达到 0.9436；
	- 加入第三个 text 后达到 0.9817；
	- 最终 20 个 text 仍保持 0.9864。
	
	L8H6 类似：
	- 第一个 text 只有 0.1225；
	- 第二个 text 后达到 0.9780；
	- 第五个 text 后达到 0.9930；
	- 最终为 0.9909。
	
	这表明这些 head 中存在少数非常有效的 text 方向，且这些方向之间具有较好的互补性
- 单个最优 text 可能比完整的 20-text 累计重构更适合作为高效探针
	L8H8 的第一个 text 的 single AUC 为 0.9860，加入第二个 text 后累计 AUC 为 0.9868，但继续加入更多 text 后反而逐步下降，最终降到 0.9626
- 存在反向强鉴伪 head
	L12H3 在当前 TextSPAN 方差顺序下，累计 AUC 从 0.5 迅速下降到 0.01 左右，最终只有 0.0142
- 累计重构不是单调提升的，真正适合完整 TextSPAN 重构的 head 很少
- 鉴伪信息更集中在 ViT-L/14 的中间层，而不是最后几层。最后层可能更偏向高层语义或任务输出，反而不保留稳定的 real/fake 区分方向
- 强 text 的语义非常分散。这说明真正起作用的可能是这些文本嵌入在 CLIP 特征空间中的投影方向，而不一定是文本字面语义本身
### 后续研究方向

1. 单 text/少量 text 选择，并比较跨数据集泛化，而不是直接使用全部 20 个 text
2. 对 top head 的 text 进行方向翻转

## AUC by Projection

Projection 的具体含义见 [[1-Projects/AIGC/Interpretability/CLIP/Summary#TextSpan 算法|Summary]]

Projection 是标量。所以计算 auc 可以直接通过看一组图像中，real 的 Projection 是否高于 fake 的 Projection
## 核心发现

1. 鉴伪强度高度一致，AUC 方向经常相反
    projection 很好地预测了 single-text 是否强，但不总是预测 real/fake 的正负方向
2. 同一个 head 内，projection 可以很好地筛选强 single-text
    但需使用 $\max(AUC_{\text{proj}},1-AUC_{\text{proj}})$，不能只按 projection AUC 从大到小排序

**projection 决定 text direction 本身是否携带鉴伪信号；single-text 决定该 direction 被重构进完整 CLIP 特征后，能否被 probe 以当前方向利用。**

- projection 强、single-text 也强：该方向本身稳定且能被完整 probe 利用
- projection 强、single-text 反向强：两者发现了同一信号，但 probe 方向相反
- projection 强、single-text 弱：完整特征归一化或 probe 组合削弱了该 head 的局部方向
- projection 弱、single-text 强：projection 的局部线性信号本身不明显，但重构后的完整特征与 probe 产生了协同

*最值得继续验证的是最后两类，因为它们揭示了 head 局部方向与完整 CLIP 鉴伪机制之间的差异*
