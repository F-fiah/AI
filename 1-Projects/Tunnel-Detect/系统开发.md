# 阶段一：基础学习

**目标**：掌握系统开发所需的编程基础和核心工具
## Python多线程编程

*   **怎么学**：
    1.  **理解核心概念**：先搞懂线程、进程、GIL（全局解释器锁）的基本概念，以及为什么在Python中多线程更适合I/O密集型任务。
    2.  **动手实践**：从最简单的`threading.Thread`创建线程开始，练习线程的启动、等待（`join`）和同步（`Lock`）。
    3.  **攻克生产者-消费者模式**：这是本项目的核心模式。练习使用`queue.Queue`实现一个线程生产数据、另一个线程消费数据的模型。
    4.  **完成一个小项目**：编写一个多线程的图片下载器，练习线程创建、队列使用和异常处理。
*   **高质量资源**：
    *   **教程**：阿里云开发者社区的《Python 多线程从入门到精通》教程，内容系统，包含实战对比。
    *   **系统课程**：**Real Python** 的 *Python Concurrency & Parallel Programming* 学习路径，涵盖`threading`、`asyncio`和`multiprocessing`，内容权威。
    *   **获取方式**：在阿里云开发者社区搜索标题；在Real Python官网的“Learning Paths”栏目查找。
## Flask后端开发

*   **怎么学**：
    1.  **跑通最小应用**：先安装Flask，编写一个只有几行代码的“Hello World”应用，理解路由（Route）和视图函数（View Function）的概念。
    2.  **学习核心组件**：逐步学习请求处理（Request）、模板渲染（Jinja2）、以及如何使用蓝图（Blueprint）组织大型应用。
    3.  **设计RESTful API**：学习如何设计符合REST规范的API接口，理解GET、POST等HTTP方法的含义。
    4.  **完成一个实战项目**：搭建一个简易的“待办事项”API，实现任务的增删改查，并通过Flask提供Web接口。
*   **高质量资源**：
    *   **书籍**：**《Flask从入门到进阶：Python Web开发工程化实践》**，该书由Flask官方团队成员撰写，内容系统全面，提供了完整的Python Web工程化学习路径。
    *   **在线课程**：国家高等教育智慧教育平台上的《Web后端开发》课程，采用Flask框架，通过“智能租房”案例展开教学。
    *   **获取方式**：在各大在线书店搜索书名；在“国家高等教育智慧教育平台”搜索课程名。
## SQLite数据库

*   **怎么学**：
    1.  **熟悉Python内置模块**：Python已内置`sqlite3`模块，无需额外安装。先学习如何连接数据库、创建游标（Cursor）。
    2.  **掌握核心SQL语句**：学习`CREATE TABLE`（建表）、`INSERT`（插入）、`SELECT`（查询）、`UPDATE`（更新）、`DELETE`（删除）这五类核心操作。
    3.  **完成一个练习**：使用`sqlite3`模块创建一个简单的电影数据库，并进行增删改查操作。
*   **高质量资源**：
    *   **官方文档**：Python官方文档中的`sqlite3`教程是最权威的参考资料，包含完整的示例代码。
    *   **教程**：W3CSchool的《Python SQLite 微课》，以微课形式讲解，适合快速上手。
    *   **获取方式**：访问Python官网文档；在W3CSchool网站搜索。

# 阶段二：核心开发

**目标**：掌握系统集成所需的关键技术，能够独立完成功能模块的开发。
## MQTT通信与paho-mqtt库

*   **怎么学**：
    1.  **理解核心模型**：搞懂MQTT的发布/订阅（Publish/Subscribe）模式，理解Broker、Topic、QoS等核心概念。
    2.  **安装并跑通示例**：安装`paho-mqtt`库，分别编写一个发布者（Publisher）和一个订阅者（Subscriber）脚本，测试消息收发。
    3.  **集成到项目中**：将MQTT客户端集成到系统主程序中，实现检测结果的上报。
*   **高质量资源**：
    *   **官方示例**：Microsoft Learn上的《使用MQTT与Azure IoT Hub通信》教程，包含`paho-mqtt`的完整Python示例代码。
    *   **SDK文档**：腾讯云开发者社区的《Python SDK》文档，提供了`paho-mqtt`的详细使用说明。
    *   **获取方式**：访问Microsoft Learn和腾讯云开发者社区搜索。
## 边缘计算系统集成与多线程实战

*   **怎么学**：
    1.  **学习线程池架构**：参考边缘视觉系统的典型设计，学习如何构建采集线程、推理线程、渲染线程的多级流水线。
    2.  **实现帧缓存队列**：使用`queue.Queue(maxsize=2)`实现帧缓存，设计“丢弃旧帧，处理最新帧”的策略。
    3.  **完成系统集成**：将摄像头采集、预处理、推理、结果上报等模块串联起来，形成一个完整的流水线。
*   **高质量资源**：
    *   **技术博客**：《从踩坑到精通：边缘网关在物联网场景下的实践与优化指南》，详细阐述了动态线程池、内存管理等性能优化策略。
    *   **实战项目**：CSDN上的《AIPC：多摄像头实时目标检测系统》，包含三级线程池（采集/推理/渲染）的完整实现。
    *   **获取方式**：在阿里云开发者社区和CSDN搜索标题。

# 阶段三：集成优化

**目标**：将各模块整合为完整系统，进行性能调优、稳定性测试和文档编写。
## Flask + ECharts 实时监控面板

*   **怎么学**：
    1.  **学习Flask-SocketIO**：实时推送需要用到WebSocket，`Flask-SocketIO`是实现这一功能的流行库。
    2.  **学习ECharts基础**：了解ECharts的图表类型和配置项，能够根据数据动态更新图表。
    3.  **完成一个监控大屏**：参考现成的Flask + ECharts项目，将你的检测结果数据通过API提供给前端，并用ECharts渲染成柱状图、折线图等。
*   **高质量资源**：
    *   **教程**：《基于Echarts + Python Flask 实时大屏监控解决方案》，提供了完整的实现方案。
    *   **可运行源码**：CSDN文库上的《Flask+ECharts实时数据看板源码》，内含10+可独立运行的图表组件，适合参考和修改。
    *   **获取方式**：在GitCode博客和CSDN搜索相关标题。
## systemd 服务与日志管理

*   **怎么学**：
    1.  **编写Service文件**：学习在`/etc/systemd/system/`目录下创建`.service`文件，配置`ExecStart`等参数。
    2.  **掌握管理命令**：学习使用`systemctl enable`（开机自启）、`systemctl start`（启动）、`systemctl status`（查看状态）等命令。
    3.  **使用journalctl查看日志**：学习使用`journalctl -u your-service -f`实时查看服务日志。
*   **高质量资源**：
    *   **实战指南**：《〖Python量化系统工程化 #08〗关了 SSH 就停？systemd 让脚本开机自启 + 异常自动拉起》，以量化系统为例，讲解了systemd的完整配置。
    *   **官方文档**：Rocky Linux官方文档中的《systemd服务与Python脚本》教程，提供了标准的配置范例。
    *   **获取方式**：在腾讯云开发者社区和Rocky Linux文档站搜索。
## 代码规范、文档编写与Git协作

*   **怎么学**：
    1.  **遵循PEP 8规范**：学习Python的官方代码风格指南PEP 8，使用工具（如`flake8`）检查代码风格。

    3.  **实践Git协作**：在项目仓库中实践Fork-PR工作流，学习如何提交Issue、创建Pull Request、进行Code Review。
*   **高质量资源**：
